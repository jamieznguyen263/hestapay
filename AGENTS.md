# HestaPay AGENTS.md

## Project identity

This repository is for **HestaPay**, not StoaHub.

HestaPay is a payment software and orchestration layer for local businesses.

Target industries:
- restaurants
- nail salons
- retail
- home services

HestaPay is **not**:
- a bank
- a payment processor
- an acquirer
- a payment infrastructure provider

HestaPay integrates with trusted payment infrastructure partners.

## Current objective

The current objective is to build polished mock product screens in code that can later be used as landing page visual assets. These are not production app features yet. These are screenshot-ready or mockup-ready UI screens for marketing use.

## Design direction

- modern
- bright
- premium fintech
- green is the primary brand color
- product-led visuals
- subtle depth
- no crypto aesthetic
- no noisy gradients
- no stock-photo feel

## Visual and content rules

- no fake testimonials
- no fake customer logos
- no fake compliance badges
- no fake PCI/SOC claims
- no unsupported performance claims
- no invented partner logos or integrations
- no fake realistic business metrics
- use abstracted or placeholder-safe UI values such as em dash, preview labels, or neutral states

## Mock screen priorities

- merchant dashboard overview
- transactions table preview
- payment link creation screen
- QR payment screen
- mobile checkout screen
- staff / tips / shift summary screen

## Engineering rules

- do not change route structure unless explicitly asked
- do not refactor unrelated files
- keep changes scoped to the assigned task
- prefer reusable components where reasonable
- keep wording partner-safe
