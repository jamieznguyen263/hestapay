# HestaPay

HestaPay is a modern payment software platform for local businesses.

## Positioning
HestaPay is a software and orchestration layer.
It is not a bank, processor, acquirer, or payment infrastructure provider.
It is designed to integrate with trusted payment infrastructure partners.

## Current build phase
Phase 1 focuses on:
- website and landing pages
- product positioning
- partner-safe messaging
- early access and demo conversion flows
- foundation for merchant dashboard, staff PWA, and customer checkout

## Target businesses
- Restaurants
- Nail salons
- Retail
- Home services

## Tech stack
- Next.js
- TypeScript
- Tailwind CSS
- App Router
